## Report a Router

Keenetic, Netcraze, Teltonika and TR-064 are written from the vendors' documentation and have not met a real device; OPNsense, pfSense and VyOS were checked in virtual machines only. If you run one of them, an issue with the model, the firmware version and what worked or did not helps more than anything else. Leave addresses, passwords and keys out of it.

## If the App Does Not Start

A desktop start that fails writes its cause to `NetworkHelm-startup-error.log` in the temporary folder: `%TEMP%` on Windows (paste it into the Explorer address bar), `/tmp` on Linux. Attach that file to an issue together with the system version and whether it runs in a virtual machine. A window of the installer or of the portable EXE that says the program does not support this version of Windows means Windows 7, 8 or 8.1 and the standard files, which need 64-bit Windows 10 or newer. The files marked `legacy` in the release are built for 64-bit Windows 7 SP1 and 8; the author has not been able to run them there yet, so a report from such a machine is welcome.
